# React Todo Application

A clean and efficient task management application built with React. This project provides a streamlined interface for tracking daily activities and managing tasks using standard CRUD (Create, Read, Update, Delete) operations.

## Features

* **Create Tasks:** Easily add new tasks to your to-do list.
* **View Tasks:** View a clear, organized list of all pending and completed items.
* **Edit Tasks:** Modify existing task details or update their status.
* **Delete Tasks:** Remove items from the list once they are no longer needed.
* **Status Tracking:** Mark individual tasks as complete or incomplete.

## Tech Stack

* **Frontend:** React, JavaScript (ES6+)
* **Styling:** CSS / HTML5
